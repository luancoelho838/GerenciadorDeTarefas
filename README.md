# Gerenciador de Tarefas

Aplicação de gerenciamento de tarefas desenvolvida em **C#**, com integração ao **MySQL**, como projeto de estudo e prática de operações CRUD e persistência de dados.

## Funcionalidades

- **Adicionar tarefas:** cadastrar tarefas com título, descrição, data de vencimento e status de conclusão.
- **Listar tarefas:** visualizar as tarefas cadastradas.
- **Atualizar tarefas:** editar as informações de uma tarefa existente.
- **Excluir tarefas:** remover tarefas pelo ID.

## Tecnologias utilizadas

- C#
- .NET 10
- MySQL
- MySQL Workbench
- MySql.Data (NuGet)
- Visual Studio

## Como executar

1. Clone o repositório.
2. Crie o banco de dados e a tabela conforme instruções do arquivo "database.sql"
3. Configure a conexão com o banco de dados no arquivo `Conexao.cs`.
4. Restaure os pacotes NuGet.
5. Execute o projeto pelo Visual Studio.

## Objetivo

Projeto desenvolvido para consolidar conhecimentos em C#, programação orientada a objetos, integração com banco de dados e organização de código, aplicando na prática as operações fundamentais de CRUD.
